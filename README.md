# Khổng Đỗ Thanh Huyền - Personal Portfolio Website

Trang web hồ sơ cá nhân, thành tích học thuật & Miss HNUE 2025 của **Khổng Đỗ Thanh Huyền** - Sinh viên năm thứ 4, Khoa Công nghệ thông tin, Trường Đại học Sư phạm Hà Nội (HNUE).

## 🌟 Điểm Nổi Bật
- **Nhan sắc & Dấu ấn:** Miss IT 2025, Top 20 Miss HNUE 2025.
- **Nghiệp vụ sư phạm:** 3 năm liên tiếp tham gia Hội thi Xử lý tình huống Nghiệp vụ Sư phạm cấp Trường (2023 - 2025).
- **Nghiên cứu khoa học:** Bán kết Euréka 2026, Giải Nhì NCKH cấp Trường HNUE 2026, Giải Nhất cấp Khoa CNTT 2026.
- **Công bố khoa học:**
  - Springer Nature CCIS 2027 (DOI: `10.1007/978-981-92-2587-3_26`)
  - Tạp chí Khoa học Giáo dục ĐH Sư phạm Hà Nội (DOI: `10.18173/2354-1075.2026-0053`)
  - IEEE ICIET 2025 (DOI: `10.1109/iciet66371.2025.11046250`)
  - Đề tài đang xét duyệt: `EN.26.202: Designing Gamified Digital ESP Learning Materials for Information Technology Students`

## 🚀 Hướng Dẫn Kích Hoạt GitHub Pages
1. Tạo repository mới trên GitHub (ví dụ: `thanh-huyen` hoặc `portfolio`).
2. Đẩy mã nguồn lên nhánh `main`.
3. Vào **Settings** -> **Pages** -> Tại mục **Branch**, chọn `main` / `root` -> Bấm **Save**.
4. Trang web sẽ có liên kết trực tuyến: `https://<ten-tai-khoan>.github.io/<ten-repo>/`.
